# CRM-система для малого бизнеса (на примере YClients для бьюти-сферы)

Данный проект представляет собой описание CRM-системы для автоматизации бьюти-салонов. Система предназначена для онлайн-записи клиентов, управления расписанием мастеров, ведения клиентской базы, финансового учёта и программ лояльности. Проект выполнен в рамках дисциплины «Программная инженерия».

## Основные возможности
- Онлайн-запись через сайт, виджеты Яндекс.Карт и ботов в Telegram/VK.
- Единое расписание всех мастеров с управлением бронированиями.
- Картотека клиентов с историей посещений и аллергиями.
- Автоматические напоминания (SMS, email, push).
- Финансовый учёт и отчётность для владельца.
- Программа лояльности: бонусы, скидки, акции.
