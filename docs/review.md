\## Чек-лист (8 вопросов)



1\. У каждого пользователя есть хотя бы одна функция в требованиях?

2\. Для каждого функционального требования есть модуль в архитектуре?

3\. Все классы из диаграммы классов упоминаются в требованиях или сценариях?

4\. Диаграмма последовательности соответствует одному из сценариев?

5\. На каждый сценарий есть хотя бы один тест-кейс?

6\. Названия ролей и терминов одинаковы во всех документах?

7\. Есть ли тест-кейс на перенос записи и на отзыв клиента?

8\. Есть ли для требований с временными характеристиками конкретные измеримые значения?
