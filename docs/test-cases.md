\# Тест-кейсы



| ID | Что проверяется | Предусловия | Ожидаемый результат |

|---|---|---|---|

| TC-01 | Успешная запись через виджет | Услуга, мастер, дата, время, контакты | Запись создана, слот заблокирован, клиент получил подтверждение |

| TC-02 | Отображение только свободных слотов | Мастер, дата | Отображаются только незанятые слоты |

| TC-03 | Отмена записи клиентом | Существующая запись | Статус «отменена», слот освобождён, уведомления отправлены |

| TC-04 | Подтверждение записи администратором | Новая запись | Статус «подтверждена», клиент получает уведомление |

| TC-05 | Автоматическое напоминание за день | Подтверждённая запись на завтра | Клиенту отправлено SMS или email-напоминание |

| TC-06 | Расчёт зарплаты мастера | Выполненные записи за период, процент мастера | Сумма рассчитана верно (выручка × процент) |

| TC-07 | Интеграция с Яндекс.Картами | Открыта карточка салона | Запись создаётся в CRM, данные синхронизированы |

| TC-08 | Перенос записи клиентом | Существующая запись, есть свободный слот | Старая запись отменена, создана новая, оба слота обновлены, уведомления отправлены |

| TC-09 | Оставить отзыв | Запись в статусе «выполнена» | Отзыв сохранён, виден администратору, привязан к мастеру и услуге |



Тест-кейсы покрывают основные функции системы и соответствуют описанным требованиям.
