\# Архитектура системы



\## Модель жизненного цикла

Выбрана итеративная модель. Требования уточняются по ходу разработки, систему удобно создавать постепенно — начиная с базовой записи и наращивая функциональность. Каждая итерация добавляет ценность и снижает риски.



\### План итераций

\- \*\*Итерация 1 (базовая).\*\* Регистрация, каталог услуг и мастеров, создание записи, простая панель администратора.

\- \*\*Итерация 2 (администрирование).\*\* Подтверждение, перенос и отмена записи, управление расписанием, кабинет мастера, отметка о выполнении.

\- \*\*Итерация 3 (уведомления и интеграции).\*\* SMS и email-напоминания, виджет Яндекс.Карт и 2ГИС, боты Telegram и VK.

\- \*\*Итерация 4 (финансы и лояльность).\*\* Финансовый учёт, отчёты, бонусы, скидки, акции.



\## Модульная архитектура



| Модуль | Назначение | Взаимодействует с |

|---|---|---|

| Интерфейс клиента | Онлайн-запись, история, бонусы, отзывы | Модуль записи, каталог, клиентская база, уведомления, лояльность |

| Интерфейс администратора и мастера | Управление записями, расписанием, клиентами | Модуль записи, клиентская база, финансы, уведомления, администрирование |

| Модуль записи и расписания | Ядро системы: бронирование, статусы, слоты | Каталог, клиентская база, уведомления, интеграции |

| Модуль уведомлений | SMS, email, push, мессенджеры | Модуль записи и расписания, клиентская база, модуль интеграции (SMS/email-шлюзы) |

| Модуль интеграции | Яндекс.Карты, 2ГИС, VK, Telegram, платёжные системы | Модуль записи, уведомления, аутентификация |

| Модуль клиентской базы | Профили, история, аллергии, предпочтения | Модуль записи, уведомления, лояльность, интерфейс клиента |

| Модуль финансов и лояльности | Учёт, зарплаты, отчёты, бонусы | Модуль записи, клиентская база, интерфейс администратора |

| Модуль аутентификации | Вход, роли, 2FA, восстановление пароля | Все модули |

| База данных | Централизованное хранилище всех сущностей | Все модули |



Каждый модуль развивается независимо и взаимодействует с другими через API или события.
