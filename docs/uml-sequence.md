\# UML-диаграмма последовательности



Диаграмма показывает взаимодействие модулей при записи клиента через виджет Яндекс.Карт.



\## Участники

\- Клиент

\- Виджет Яндекс.Карт

\- Integration API

\- Booking Module

\- Schedule Module

\- Notification Module

\- База данных



\## Последовательность шагов



1\. Клиент выбирает услугу, мастера и дату в виджете.

2\. Виджет через Integration API запрашивает у Booking Module свободные слоты.

3\. Booking Module обращается к Schedule Module.

4\. Schedule Module выполняет запрос к БД и возвращает список свободных слотов.

5\. Слоты отображаются клиенту.

6\. Клиент выбирает время, вводит имя и телефон, подтверждает запись.

7\. Booking Module создаёт запись через Schedule Module, обновляя статус слота на «занят».

8\. Schedule Module подтверждает успех.

9\. Booking Module отправляет уведомление через Notification Module.

10\. Notification Module сохраняет уведомление и отправляет SMS или email клиенту.

11\. Виджет показывает клиенту подтверждение.



Все действия логируются в модуле аудита.
